Exercise evaluation for type 1 diabetes

Reads a Nightscout site and an activity file, then compares what happened around each exercise session against the published guidance. Everything runs in this browser. No data is uploaded anywhere, and there is no server to send it to.

This is not medical advice. It reads a record after the event and compares it against population-level guidance, without knowing your history, your insulin sensitivity, what else was happening that day, or what your clinical team has told you. Much of the guidance it quotes is expert consensus rather than trial evidence, and each finding says which it is. Discuss any change to your insulin or your food with the team who look after your diabetes.

1 Your Nightscout site

The site has to allow this page to read it, and most do not by default

A browser will not let one website read another unless the second one says it may. A stock Nightscout sends no such header, so the fetch fails before any data is read. The site owner adds one word to a setting they already have: 

ENABLE=<whatever is already there> cors
CORS_ALLOW_ORIGIN=*

Then restart the service. Setting CORS_ALLOW_ORIGIN without adding cors to ENABLE does nothing, and does so silently, which is the usual reason a second attempt fails the same way as the first.

The token is only needed where the site is not readable without one. Most Nightscout sites allow anonymous reads, so leave it blank and try first. If you do need one, create a read-only subject token in Admin Tools rather than using the API secret, which cannot be sent from a browser at all.

2 Your activity data

Drop a file here, or click to choose one.

The Health Connect export zip, a SQLite database, a Strava or Garmin archive, or an individual FIT, TCX, GPX, CSV or JSON file. More than one file can be added, and duplicate sessions are dropped.

    Where the Health Connect export comes from, and what is in it

    On Android, Health Connect writes a scheduled export to a cloud storage app of your choosing. There is no on-demand export: set up a daily, weekly or monthly schedule, then collect the file from wherever it was written. It is named Health Connect.zip unless you renamed it at setup.

    The file is not encrypted, despite a claim to the contrary that circulates widely. It holds one plain SQLite database, which is why this page can read it. It also retains your GPS route data at full precision. Nothing leaves this browser here, but that is worth knowing before you share the file anywhere else.

    Every one of these is optional. Each one that is left blank makes some part of the analysis less certain, and the report says which part.

    What the risk group changes

    It shifts every glucose threshold in the report. The EASD and ISPAD position statement grades hypoglycaemia risk from awareness, then from time below 3.9 mmol/L (70 mg/dL) over three months, then from whether a severe episode occurred in the last six months. Each step up raises the carbohydrate threshold during exercise from 7.0 to 8.0 to 9.0 mmol/L (126 to 145 to 161 mg/dL), and the floor for the first ninety minutes afterwards from 4.4 to 5.0 to 5.6 mmol/L (80 to 90 to 100 mg/dL).
